# C++ OOP — Class Design & Operator Overloading

A practical C++ reference built around a single `Shop` class, covering the core OOP concepts taught in university courses.

## What's covered

- Class structure: private attributes, public interface
- `const` and `static` members
- Constructors: default, full, partial
- Destructor and memory management
- Deep copy vs shallow copy
- Copy constructor
- Assignment operator `=`
- Getters and setters (including static)
- Arithmetic operators: `+`, `+=`
- Increment operators: `++` pre and post
- Relational operators: `>=`
- Special operators: `[]`, `()`, cast, `!`, `~`
- Stream operators: `<<`, `>>`

## How to run

Open in any C++ IDE (Visual Studio, CLion, Code::Blocks) or compile from terminal:

```bash
g++ cpp-oop-fundamentals.cpp -o main
./main
```
